# Orioye Blessing Esther Portfolio

Professional portfolio of a Data Engineer, Project Manager, and AI Solutions Enthusiast featuring technical projects and architecture insights.

## 🚀 Features

- **Home**: Introduction and high-level overview.
- **About**: Detailed professional background and expertise.
- **Projects**: Showcase of technical projects and architecture insights.
- **Contact**: Direct ways to get in touch.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS 4
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React

## 📦 Installation & Setup

### Prerequisites

- Node.js (Latest LTS recommended)

### Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ayaoba24/Orioye-Blessing-Esther-Profolio.git
   cd Orioye-Blessing-Esther-Profolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
